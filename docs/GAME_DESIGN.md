# GAME_DESIGN.md — طراحی بازی

## پرسپکتیو و دوربین

- **۲بعدی top-down سه‌چهارم** — تصمیم ثابت کل پروژه (هیچ‌وقت side-scroll قاطی نمی‌شود).
- تایل ۱۶px، دوربین zoom=3 → ۴۸px روی صفحه؛ `pixelArt: true` + `roundPixels`.
- عمق با `setDepth(y)` (پایین‌وسط = خط زمین). سایهٔ جدا زیر کاراکتر.
- دوربین: follow نرم (lerp 0.14)، bounds = مرز دنیا.

## حلقهٔ گیم‌پلی اصلی (هدف نهایی)

اکتشاف با اسب → برخورد با دنیا (NPC/حادثه/جایزه) → کسب پول (مأموریت/شکار/تجارت) → تجهیز بهتر → پیشرفت داستان → واکنش دنیا (قانون/اعتبار/قیمت).

وضعیت: حلقهٔ «اکتشاف ← تعامل ← دیالوگ» در فاز ۱ ✅؛ بقیه طبق نقشه راه.

## کنترل‌ها (نهایی فاز ۱)

WASD/جهت‌ها حرکت · Shift دویدن · E تعامل · Enter دیالوگ · Esc مکث. موس از فاز ۵ (نشانه‌گیری) اضافه می‌شود.

## سیستم‌ها — وضعیت واقعی

| سیستم | وضعیت | یادداشت |
|---|---|---|
| حرکت بازیکن (accel/drag/maxVelocity، نرمال‌سازی قطری) | ✅ پیاده‌شده+تست مرورگر | سرعت‌ها در `GameConfig` |
| ماشین حالت بازیکن (idle/walk/run/frozen) | ✅ | anim همیشه از velocity واقعی، نه نیت |
| برخورد | ✅ | تایل‌های مانع + body پروپ‌ها + مرز دنیا |
| دوربین | ✅ | follow+lerp، بدون jitter |
| ساعت دنیا و شب/روز | ✅ پیاده‌شده+تست واحد | `TimeSystem` تک‌منبع؛ ۱ روز = ۱۲ دقیقه |
| تعامل | ✅ پیاده‌شده+تست واحد | نزدیک‌ترین هدف، بدون repeat-hold |
| دیالوگ فارسی | ✅ | تایپ‌رایتر، freeze بازیکن |
| NPC گشت‌زنی | ✅ حداقلی | فاز ۳: schedule/ادراک/سطح‌بندی شبیه‌سازی |
| اسب | ⬜ فاز ۴ | |
| سلاح/رزم (data-driven، hitscan یا پرتابه — تصمیم در فاز ۵) | ⬜ فاز ۵ | |
| جرم/شاهد/قانون/اعتبار | ⬜ فاز ۶ | |
| مأموریت‌ها | ⬜ فاز ۷ | |
| اینونتوری/اقتصاد/مغازه | ⬜ فاز ۸ | |
| save/load نسخه‌دار | ⬜ فاز ۸ | |
| حوادث پویای دنیا | ⬜ فاز ۹ | |
| صدا | ⬜ فاز ۱۰ (شروع از فاز ۲: محیط ساده) | |

## اتمسفر

- فاز ۱: ساعت + تینت رنگی (سپیده 0.16/نارنجی روشن، غروب 0.24/نارنجی، شب 0.45/آبی تیره) — از `PHASE_VISUALS`.
- غبار دویدن (particle). فازهای بعد: صدا، آب‌وهوا، دود سالون، باد.

## فلسفهٔ رزم (برای فاز ۵)

جای‌گیری/تایمینگ/پوشش — نه تورم HP. سلاح data-driven؛ مسیر بصری گلوله = محاسبهٔ واقعی آسیب.

## فلسفهٔ قانون (برای فاز ۶)

سوءظن ← بررسی ← جرم تأیید ← تعقیب ← نتیجه؛ شاهد فقط آنچه «ادراک» کرده را گزارش می‌کند؛ بازیکن باید بفهمد چرا تعقیب می‌شود.
